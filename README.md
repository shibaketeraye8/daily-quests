# Квесты дня — нативное приложение для iPhone

Тёмное фэнтези-приложение с ежедневными квестами: 10 000 шагов, XP, уровни, стрик,
достижения и напоминание на iPhone. Шаги считает датчик движения (CoreMotion),
интернет и аккаунты не нужны, все данные хранятся на телефоне.

Здесь лежит готовый исходник и настройка сборки `.ipa` в облаке GitHub.
Собирать на Mac не нужно: GitHub соберёт приложение на своём macOS-сервере,
а установишь ты его на Windows через Sideloadly с бесплатным Apple ID.

---

## Что понадобится

- Windows-компьютер с интернетом.
- iPhone (iOS 16 или новее).
- Бесплатный Apple ID (тот, что используется в App Store).
- Кабель для iPhone.
- Около 30–40 минут на первый раз.

---

## Шаг 1. Аккаунт GitHub

1. Открой https://github.com/signup
2. Зарегистрируйся (email, пароль, имя пользователя).
3. Подтверди email.

GitHub нужен только как «сборочный цех». Аккаунт бесплатный.

---

## Шаг 2. Создать репозиторий

1. Открой https://github.com/new
2. **Repository name**: `daily-quests-ios`
3. Выбери **Public** (важно: на бесплатном тарифе сборка macOS доступна только в публичных репозиториях).
4. Галочки `Add a README file` и `.gitignore` **не ставь**.
5. Нажми **Create repository**.

---

## Шаг 3. Загрузить файлы

На странице пустого репозитория будет ссылка **uploading an existing file**.

1. Открой папку `ios-native` на компьютере.
2. Выдели **всё содержимое** папки: `DailyQuests`, `.github`, `project.yml`, `README.md`, `.gitignore`.
   Важно: загружать нужно содержимое папки, а не саму папку `ios-native`,
   иначе GitHub не найдёт файл сборки.
3. Перетащи выделенное в окно браузера на странице GitHub.
4. Дождись, пока все файлы появятся в списке.
5. Внизу нажми **Commit changes**.

Проверка: на главной странице репозитория должны быть видны папки `DailyQuests`,
`.github` и файл `project.yml`.

---

## Шаг 4. Собрать приложение

1. В репозитории открой вкладку **Actions**.
2. Если GitHub предложит включить workflows — нажми **I understand my workflows, go ahead and enable them**.
3. Слева выбери **Build IPA**.
4. Справа нажми **Run workflow** → **Run workflow**.
5. Обнови страницу через 10 секунд — появится запуск с жёлтым кружком. Идёт сборка 5–10 минут.
6. Когда кружок станет зелёной галочкой — открой запуск, внизу в разделе **Artifacts**
   скачай **DailyQuests-ipa** (это zip-архив).
7. Распакуй архив — внутри файл **DailyQuests.ipa**. Сохрани его, он ещё понадобится.

Если кружок красный — открой запуск, открой шаг с ошибкой и пришли текст ошибки.
Первый запуск — это первая настоящая компиляция кода, поэтому возможны правки.

---

## Шаг 5. Подготовить Windows

1. Установи **iTunes** с сайта Apple: https://www.apple.com/itunes/download/win64
   (именно эта версия, не из Microsoft Store — она ставит нужные драйверы для iPhone).
2. Установи **Sideloadly**: https://sideloadly.io
3. Подключи iPhone кабелем. На телефоне нажми **Доверять этому компьютеру** и введи пароль.

---

## Шаг 6. Установить приложение на iPhone

1. Запусти **Sideloadly**.
2. В строке **Apple ID** введи свой Apple ID (email).
3. Перетащи файл **DailyQuests.ipa** в окно Sideloadly (или нажми значок IPA и выбери его).
4. Убедись, что в списке устройств выбран твой iPhone.
5. Нажми **Start**.
6. Введи пароль от Apple ID. Если включена двухфакторная защита — введи код, который придёт на iPhone.
7. Дождись надписи **Done**. Приложение появится на экране iPhone.

---

## Шаг 7. Разрешить приложение на iPhone

1. Открой **Настройки → Основные → VPN и управление устройством → Профиль разработчика** (с твоим Apple ID) → **Доверять**.
2. Для iOS 16 и новее: **Настройки → Конфиденциальность и безопасность → Режим разработчика** → включи → перезагрузи iPhone.
3. Запусти «Квесты». Разреши доступ к движению и активности (для шагов) и уведомления (для напоминания).

---

## Как это работает

- Каждый день генерируются 5 квестов. Один всегда шаги.
- Шаги подтягиваются автоматически из датчика движения за сегодня.
- Остальные квесты отмечаешь сам: кнопки `+`, `−`, `✓` или ввод числа.
- День идёт в стрик, если закрыто 3 из 5 квестов. Все 5 — идеальный день, +50 XP.
- За квесты дают XP, за XP — уровни и титулы (Странник → Воин → Рыцарь → Паладин → Мастер → Легенда).
- В настройках: сложность (Лёгкий ×0.7 / Обычный ×1.0 / Хардкор ×1.3), напоминание, синхронизация шагов, сброс.
- В журнале: график XP за 7 дней и история последних 14 дней.

Шаги обновляются, когда приложение открыто или возвращается на передний план —
iOS не разрешает фоновое чтение датчика без специальных разрешений.

---

## Важное ограничение бесплатного Apple ID

- Подпись действует **7 дней**. Через неделю приложение перестанет запускаться.
- Чтобы продлить: снова открой Sideloadly и подпиши **тот же `.ipa`** ещё раз (пересобирать в GitHub не нужно).
- Одновременно можно держать не больше 3 своих приложений на бесплатном Apple ID.
- Push-уведомления из интернета и виджеты недоступны — приложение использует локальные уведомления, им это не мешает.

## Если что-то не так

**В Actions нет вкладки или нет кнопки Run workflow**
Проверь, что файл лежит по пути `.github/workflows/build-ipa.yml` в корне репозитория,
а репозиторий публичный.

**В репозитории не появилась папка `.github`**
Создай файл вручную: **Add file → Create new file**, в поле имени введи
`.github/workflows/build-ipa.yml`, открой локальный файл
`ios-native\.github\workflows\build-ipa.yml` в Блокноте, скопируй всё содержимое,
вставь на GitHub и нажми **Commit changes**.

**Sideloadly: `Unable to install ...` или ошибка подписи**
Смени идентификатор приложения: в файле `project.yml` найди строку
`PRODUCT_BUNDLE_IDENTIFIER: com.dailyquests.hero` и замени на что-то уникальное,
например `com.твоёимя.dailyquests`. Затем снова запусти сборку в Actions.

**Приложение установилось, но не открывается**
Проверь доверие профилю разработчика и включённый режим разработчика (Шаг 7).

**Не считаются шаги**
Настройки iPhone → Конфиденциальность → Движение и фитнес → «Квесты» → включить.
Датчик считает шаги с полуночи; если телефон лежал без движения — шагов не будет.

**Не приходит напоминание**
Настройки iPhone → Уведомления → «Квесты» → разрешить. Затем в приложении
выключи и снова включи напоминание.

## Структура проекта

```
.github/workflows/build-ipa.yml   сборка .ipa в облаке GitHub
project.yml                       описание Xcode-проекта (генерируется XcodeGen)
DailyQuests/
  DailyQuestsApp.swift            точка входа
  Info.plist                      настройки приложения
  Theme.swift                     цвета, шрифты, карточки
  Models/QuestPool.swift          пул квестов и генератор дня
  Models/GameState.swift          XP, уровни, стрик, достижения, сохранение
  Services/PedometerService.swift шаги через CoreMotion
  Services/Reminder.swift         локальные уведомления
  Views/                          экраны: квесты, герой, журнал, настройки
  Assets.xcassets/                иконка и цвета
tools/make-icons.ps1              перегенерация иконок (необязательно)
```
